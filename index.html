独立开发者，相信小而美的产品力量。

从想法到上线，一个人就是一支团队

我是 Lucas Li，一名独立软件开发者。白天写 Java 经纪业务系统，夜晚和周末用 HTML5 Canvas 做游戏、用原生 JS 搭应用原型。

我相信好的产品不需要庞大的团队和复杂的框架——一份热爱、足够的细节打磨，就能创造出让人会心一笑的东西。从网页游戏到 Web 应用，再到 IDEA 插件，每个作品都倾注了同样的用心。

擅长 Java 后端（恒生 UF3.0/JRESCloud）、HTML5 游戏开发、Web 应用原型设计、IntelliJ 插件开发、Cloudflare Pages 部署。偏好珊瑚橙视觉风格与卡通萌系 UI。
